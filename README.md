# SKOLTECH_ML_prep

Учебные задачи по классическому ML и введению в нейросети. Каждая папка — отдельная задача с ноутбуком.

| Папка | Задача | Методы | Результат |
|---|---|---|---|
| `task_1` | Прогноз доходности золота | линейная регрессия, feature engineering | — |
| `task_2` | Предсказание сердечно-сосудистых заболеваний (UCI Heart Disease) | логистическая регрессия | accuracy 0.82 |
| `task_3` | Классификация и регрессия на синтетических 2D-наборах и housing | SVM, SVR | — |
| `task_4` | Классификация цифр и детекция машин на видео | SVM + HOG / SIFT, скользящее окно | accuracy 0.996 (HOG) |
| `task_5` | Перцептрон с нуля на NumPy и на PyTorch | регуляризация, трекинг loss | — |
| `task_6` | Классификация дорожных знаков (12 630 тестовых изображений) | LeNet-5, модифицированная CNN, AlexNet; аугментации, WeightedRandomSampler, cyclical LR | AlexNet: accuracy 0.965, balanced accuracy 0.958 |
